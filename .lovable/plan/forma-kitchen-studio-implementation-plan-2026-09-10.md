# FORMA Kitchen Studio — Implementation Plan

## Overview
Build a polished three-page renovation website for an original premium brand, using the supplied concept and reference only for quality and direction. The site will prioritize consultation leads through strong imagery, trust, project evidence, and clear calls to action.

## Pages and shared structure
- Create **Home**, **About Us**, and **Contact Us** as separate pages with unique search/social metadata.
- Add a shared sticky navigation, responsive mobile menu, footer, consultation links, and a floating kitchen assistant on every page.
- Use the FORMA Kitchen Studio identity and the tagline “Designed for living. Built to last.”

## Home page
- Full-screen photographic hero with trust markers and two focused actions.
- Four-part trust strip and six image-led service entries.
- A prominent, touch-friendly before/after slider with multiple selectable projects.
- Asymmetric project portfolio, four-step process, animated placeholder statistics, three testimonials, and an image-backed consultation section.

## About page
- Editorial page with a large photographic introduction.
- Story, philosophy, design approach, craftsmanship, client process, differentiators, team, and final consultation invitation.
- Mix large images, restrained number details, short editorial labels, and spacious split layouts.

## Contact page
- High-converting project enquiry form with all requested fields and client-side validation.
- Clear loading, success, and error states; submission will be simulated because no data service was requested.
- Clearly labeled placeholder phone, email, hours, service area, and a styled location placeholder.

## Kitchen assistant
- Use one in-memory conversation that resets on refresh, based on the skipped history questions.
- Add predefined, helpful answers for renovation cost, timing, services, design support, and booking.
- Include suggested prompts, typing feedback, accessible controls, mobile layout, and focus management.
- Keep the responder isolated so a private server-side AI connection can replace it later.

## Visual system and media
- Build an ivory, charcoal, warm stone, and restrained bronze token system with editorial serif headings and contemporary sans-serif text.
- Generate a cohesive set of realistic architectural kitchen photography for the hero, services, transformations, portfolio, About page, and final consultation sections.
- Use sharp editorial framing, restrained borders, minimal radii, generous spacing, and subtle professional motion.

## Interaction and accessibility
- Implement scroll-aware navigation, reveal transitions, hover image movement, animated counters, draggable comparison slider, keyboard/focus states, and reduced-motion support.
- Ensure semantic headings, labels, useful image descriptions, touch targets, and no horizontal overflow.

## Verification
- Check all three pages at desktop and mobile widths.
- Exercise navigation, mobile menu, slider dragging, form validation/success, assistant opening/sending/closing, and all consultation links.
- Confirm the preview builds cleanly and resolve any runtime or layout errors.
