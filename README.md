# FORMA KITCHEN STUDIO
> **Designed for living. Built to last.**

FORMA Kitchen Studio is an architectural interior design, custom cabinetry, and premium kitchen remodeling company website built with React 19, TypeScript, TanStack Start & Router, and Tailwind CSS.

---

## Brand Overview

- **Company**: FORMA Kitchen Studio
- **Tagline**: *"Designed for living. Built to last."*
- **Positioning**: Premium architectural kitchen design, remodeling and bespoke millwork studio.
- **Core Services**:
  1. Complete Kitchen Renovation
  2. Custom Cabinetry & Architectural Joinery
  3. Kitchen Design & Spatial Layout Planning
  4. Countertops & Natural Stone Surfaces
  5. Layered Lighting & Electrical Details
  6. Flooring & Tactile Finishing Details
  7. End-to-End Dedicated Project Management

---

## Architectural Features & UX Highlights

1. **Interactive Before / After Renovation Slider**:
   - Real-time drag comparison with smooth split line and central grab handle.
   - Project switcher featuring 3 distinct architectural transformations:
     - *Project 01: Oak & Stone Kitchen*
     - *Project 02: Modern Family Kitchen*
     - *Project 03: Warm Minimal Kitchen*
   - Real before and after photography showcasing structural expansion, cabinetry millwork, and stone details.

2. **Persistent AI Renovation Assistant**:
   - Accessible from every page via a refined floating trigger at bottom-right.
   - Pre-configured consultation guidance on costs, timelines, service scopes, and booking.
   - Contextual quick links to schedule an on-site consultation.

3. **Lead-Generation Engine**:
   - Comprehensive multi-attribute consultation intake form with Zod schema validation.
   - Interactive feedback states (loading spinner, validation alerts, success acknowledgment).
   - Studio coverage area and service radius visualization.

4. **Curated Editorial Aesthetic**:
   - Warm ivory / soft off-white background (`#FAF8F5`) with deep charcoal text (`#181614`), warm stone/beige surfaces, and subtle metallic bronze accents.
   - High-contrast editorial typography (`Playfair Display`, `Cormorant Garamond`) paired with modern sans-serif (`Plus Jakarta Sans`, `Manrope`).
   - Generous whitespace, refined micro-borders, and subtle hardware-inspired hover transitions.

## Getting Started

### Prerequisites
- Node.js (v20+ recommended)
- npm or bun

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Typecheck & Formatting
```bash
npm run typecheck # or tsc --noEmit
npm run format
```

### Production Build
```bash
npm run build
```
