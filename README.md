# Form & Flow Kitchens

Build a complete, production-quality website for a premium Kitchen Renovation & Remodeling Company.

REFERENCE:
https://radiant-replica.vercel.app/

Use this website as a visual and conversion-quality reference only. Study its premium renovation feel, large hero imagery, typography, spacing, trust-building sections, before/after transformation presentation, statistics and strong consultation CTA.

DO NOT create a pixel-perfect clone.
DO NOT copy the company name, logo, exact wording, branding, or identity.
Create an ORIGINAL kitchen-renovation brand and original visual identity inspired by the same level of quality.

The website should look like a real, established, high-end renovation company that could compete with professional kitchen remodeling businesses.

==================================================
PRIMARY GOAL

The website's main goal is to convert visitors into kitchen renovation consultation leads.

The visitor journey should be:

Hero → Build Trust → Show Services → Show Before/After Results → Explain Process → Show Proof → Strong CTA → Contact

Every section should have a clear purpose and naturally move the visitor toward booking a consultation.

Do not make the website feel like an AI-generated template.
